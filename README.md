# Конная кавалерия — лендинг конных прогулок

Небольшой статичный сайт про конные прогулки и прокат. Проект собран на чистых HTML/CSS/JS без фреймворков.

## Как запустить

1. Откройте файл `index.html` в браузере.
2. Либо запустите локальный сервер:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Структура проекта

- `index.html` — основной HTML-файл со всеми секциями.
- `styles.css` — стили (mobile-first, типографика, сетки).
- `script.js` — интерактивность: меню-бургер, фильтры галереи, валидация формы.
- `assets/` — изображения-заглушки в формате `.svg`.

## Форма заявки

Форма проверяет имя, телефон и сообщение. При успехе показывается подтверждение, имитирующее отправку заявки в Telegram-бота.
